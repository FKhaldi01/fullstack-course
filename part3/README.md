# Phonebook Backend

Phonebook API built with Node.js and Express.

[Live App](https://your-render-url-here.onrender.com)

## Running the app

```bash
npm install
npm run dev
```

## API

- `GET /api/persons` - get all contacts
- `POST /api/persons` - add a contact
- `PUT /api/persons/:id` - update a contact
- `DELETE /api/persons/:id` - delete a contact
- `GET /info` - show app info
